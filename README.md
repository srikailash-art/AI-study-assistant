AI Study Assistant

Project Overview

AI Study Assistant is an AI-powered student utility application built using Python, Streamlit, and the Google Gemini API.

Features

- AI Study Notes Generator
- AI Text Summarizer
- AI Question Answering
- AI Concept Explainer
- AI Quiz Generator
- AI Answer Improvement
- Empty input validation
- API error handling

Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-dotenv

Installation

Install the required packages:

"pip install -r requirements.txt"

API Key Setup

Create a ".env" file in the project folder and add your Gemini API key:

"GEMINI_API_KEY=your_actual_api_key"

Never upload your ".env" file or share your API key.

Run the Application

Run this command in the project folder:

"streamlit run app.py"

Project Purpose

This application helps students summarize notes, understand concepts, generate practice quizzes, answer questions, and improve written answers using AI.
